# Bernardo Link Profile

Página “link na bio” minimalista criada com React, TypeScript strict, Vite, Tailwind CSS e GSAP. Não utiliza Next.js.

## Executar

```bash
npm install
npm run dev
```

O Vite exibirá o endereço local no terminal, normalmente `http://localhost:5173`.

## Build de produção

```bash
npm run build
npm run preview
```

## Personalização

Os dados do perfil, links, redes sociais, Discord e Spotify ficam centralizados em `src/data/profile.ts`. Os assets locais ficam em `public/images`.

## Comandos

- `npm run dev` — desenvolvimento com Vite
- `npm run build` — TypeScript strict e build otimizado
- `npm run preview` — prévia do build
- `npm run lint` — ESLint
- `npm run format` — Prettier
